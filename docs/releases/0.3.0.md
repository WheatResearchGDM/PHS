PHS Reader 0.3.0 — destino escolhido na exportação

- Removida a seleção de destino das configurações.
- Cada clique em Exportar permite escolher OneDrive direto, OneDrive instalado, pasta do aparelho ou Salvar como.
- Preparada integração direta com Microsoft Graph: autorização na página Microsoft, sessão protegida pelo Android Keystore, navegação pelas pastas e confirmação de substituição de arquivos.
- A conexão direta **depende do registro do PHS Reader na Microsoft**. O APK pede o ID público do aplicativo. O registro não foi criado nesta entrega, porque ainda não há acesso confirmado ao diretório Microsoft da organização.
- As operações de arquivos usadas não são APIs medidas/cobradas do Graph; nenhum recurso pago é contratado pelo aplicativo. O acesso ao registro depende das permissões e do ambiente Microsoft existentes.
- [Roteiro para o administrador registrar o aplicativo sem contratar recursos pagos](https://github.com/WheatResearchGDM/PHS/blob/codex/phs-reader-v0.3/docs/REGISTRO_MICROSOFT.md).

Instale por cima da versão anterior publicada em Releases, sem desinstalar, para preservar as coletas. Câmera e envio na conta OneDrive real precisam de validação no aparelho.

Validação: 57 testes automatizados aprovados, Android Lint sem erros e APK assinado com a mesma chave das versões anteriores de Releases. Os testes de Microsoft Graph usam respostas simuladas; não substituem o teste de login e envio com o registro real.
